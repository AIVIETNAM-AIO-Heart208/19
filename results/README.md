# Kết quả

- metrics/: CSV kết quả đo và đối chiếu correctness.
- figures/: biểu đồ dùng trong báo cáo.
- applications/: luật và pattern đã chọn để diễn giải.

Mỗi kết quả cần gắn với cấu hình, seed, phiên bản code, môi trường và câu lệnh tái tạo.
Không commit output mining quá lớn. Không đưa số liệu minh họa vào như kết quả đo thật.
